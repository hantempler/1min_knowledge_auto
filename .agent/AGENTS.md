## ⚡ [절대 원칙 1] 크로스 환경 무중단 이어하기를 위한 실시간 상황 기록 (2026-10-29 강력 지침 제정)
**사용자가 집, 사무실, 랩탑 등 어느 환경에서 작업을 열더라도 지난 작업 결과를 1초의 지체 없이 그대로 이어갈 수 있도록, 모든 상태 변화와 작업 맥락을 `.agent/` 내에 실시간으로 완벽하게 기록·동기화해야 합니다.**

1. **상황 기록의 즉시성 (Zero-Lag Sync)**:
   - 기획 추가, 렌더링 완료, 업로드 성공/실패, 쿼터 제한 도달 등 **어떤 이벤트가 발생하든 즉시** `.agent/docs/HANDOVER_SUMMARY.md` 및 `.agent/docs/TOPICS_DASHBOARD.md`에 현재 상태와 '다음 작업 시작 지점'을 실시간 기록한다.
2. **크로스 환경 인수인계 무결성 유지**:
   - 다른 기기나 새로운 세션에서 에이전트가 투입되었을 때, 이전 대화를 일일이 묻지 않고도 `.agent/` 폴더만 읽으면 **"어디까지 완료되었고, 지금 무엇을 해야 하는지"**를 즉각 100% 파악할 수 있는 상태를 항시 유지한다.
3. **금지 사항**:
   - 내부 메모리나 세션 컨텍스트에만 작업 내용을 남겨두고 문서 기록을 누락하여, 환경 전환 시 작업이 단절되거나 과거 작업으로 되돌아가게 만드는 행위를 절대 금지함.

## ⚡ [절대 원칙 2] 상태 변화 시 즉시 대시보드/계획표 동기화
1. **소재가 늘어날 때 (기획 추가)**:
   - 신규 기획안이 추가되거나 번호/소재가 확장되는 즉시 `topics.json`, `.agent/docs/SHORTS_100_TOPICS_PLAN.md`, `.agent/docs/TOPICS_DASHBOARD.md`에 즉시 반영할 것.
2. **영상을 만들었을 때 (제작/렌더링 완료)**:
   - 렌더링이 완료되는 즉시 `topics.json` 상태를 `RENDERED`로 변경하고 대시보드에 즉각 반영할 것.
3. **업로드하거나 상태가 바뀔 때 (발행 완료/취소/제한)**:
   - 유튜브 업로드가 성공하거나, 취소되거나, 예약되거나, 삭제 등 상태가 바뀔 때마다 즉시 `topics.json`, `strategic_upload_state.json`, `.agent/docs/TOPICS_DASHBOARD.md`, `.agent/docs/UPLOAD_MASTER_PLAN_REMAINING_74.md`의 링크와 상태를 무조건 실시간 동기화할 것.

## ⚡ [절대 원칙 3] 독단적 업로드 금지 및 발행 시간 엄수
1. **독단적 업로드 절대 금지**:
   - 사용자의 명시적인 직접 승인("업로드해", "유튜브에 올려")이 없는 한 절대로 업로드 스크립트를 임의로 실행하지 말 것.
2. **새벽 비공개 예약 절대 금지**:
   - 표준 발행 원칙은 **`즉시 전체 공개 (public)`** 또는 **사용자가 명시적으로 승인한 골든타임(08:00, 11:45, 12:45, 17:30, 18:45, 21:30 KST)**임. 시청자가 없는 새벽 시간대(23:00~07:00) 기계적 예약 발행을 절대 금지함.
